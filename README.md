# AgroAlerta

Cuaderno de campo para registrar parcelas, documentar señales con fotografías y seguir su evolución. La aplicación ofrece recorridos para productores, cooperativas y especialistas.

## Probar el recorrido principal

Entra como productor y abre **Mis parcelas**. Registra el nombre y el cultivo. En la tarjeta selecciona **Nuevo caso**, carga una imagen, confirma su calidad y añade el contexto. Desde el resultado puedes pedir una revisión. Cambia al perfil especialista en la misma pestaña para contestarla.

Recargar la página inicia un cuaderno vacío. El tablero de la cooperativa carga tres registros de referencia de `datos/campo.json`. Las acciones requieren conexión y los datos introducidos se mantienen durante la sesión de la pestaña.

HTML, CSS y JavaScript sin dependencias de ejecución. GitHub Pages sirve el contenido de la raíz de la rama principal. Los créditos de las fotografías están en `creditos.html`.
